COSA CAMBIA
  - Scontrini (menu Contabilita'): dal telefono "Fotografa lo scontrino" (o un file JPG/PNG/PDF fino
    a 8 MB) e la nota obbligatoria; "Leggi lo scontrino" manda una copia ridotta a OCR.space (2-5
    secondi) e propone totale, data, fornitore, pagato con (cassa/banca) e righe. Si corregge e si
    registra: un movimento su "Uscite da classificare" con la foto SC2026-001.jpg. Senza chiave o
    senza risposta si scrive tutto a mano.
  - Fornitore: riconosciuto per partita IVA ("gia' in elenco") o per nome (gli si aggiunge la
    partita IVA letta), "forse e' uno di questi", "Nuovo fornitore" con i dati letti da correggere,
    oppure "Scegli dalla lista dei fornitori".
  - Chi carica non modifica piu': "I miei scontrini" in sola lettura. Presidente e Tesoriere
    verificano dalla scheda: righe con la categoria, unisci, aggiungi, sconti negativi,
    quadratura, "Registra la divisione" (un movimento per categoria); "Salva i dati" (totale, data,
    fornitore, conto), "Aggiungi una foto", "Elimina lo scontrino".
  - Stati: Da verificare, Da quadrare, Verificato. La chiusura dell'anno controlla anche gli
    scontrini da quadrare.
  - Fornitori (dalla pagina Scontrini): partita IVA, comune, movimenti, possibili doppioni da
    unire, modifica (il nome cambia anche nei movimenti), togli dalla lista, elimina se mai usato.
  - Prima Nota: icona sui movimenti nati da uno scontrino; importo, data e conto si cambiano solo
    dalla scheda dello scontrino; il campo Fornitore propone solo quelli in elenco.
  - Permessi: ruolo nuovo CONSIGLIERE (scontrini + Prima Nota in sola lettura); il Segretario ora
    vede la Prima Nota in sola lettura e carica scontrini; Revisore: scontrini in sola lettura.
  - Gli scontrini si registrano dall'anno di avvio della contabilita' (2027; prima solo con un anno
    contabile di prova, come nel collaudo): fino al 31/12/2026 quelli veri restano in gestionale-acv.

LOCALE (Laragon)
  1. Estrarre lo ZIP nella radice (sovrascrivere); cancellare LEGGIMI-v0.38.0.txt.
  2. Nel .env aggiungere (la chiave e' quella di gestionale-acv, non va scritta altrove):
       OCR_SPACE_KEY=la-chiave
     Con Avast: eccezione https://api.ocr.space/* (Impostazioni > Generale > Eccezioni), come per
     la prova di oggi.
  3. php artisan migrate
     php artisan db:seed --class=RuoloSeeder
     php artisan db:seed --class=SezioneSeeder
  4. php artisan test   -> 135 superati (non serve la chiave: i test fingono OCR.space)
  5. Un consigliere di prova: php artisan tinker
       App\Models\User::create(['name' => 'Consigliere Prova', 'email' => 'consigliere@prova.it',
         'password' => 'password', 'ruolo' => 'consigliere', 'attivo' => true]);
  6. git add -A && git commit -m "v0.39.0: Scontrini dal telefono con OCR"
  7. npm run build ; git archive -o deploy.zip HEAD ; build.zip da public\build

SERVER
  Come le ultime (deploy.md par. 5: unzip, build.zip, migrate --force, optimize:clear e cache),
  con in piu' dopo "php artisan migrate --force":
     php artisan db:seed --class=RuoloSeeder --force
     php artisan db:seed --class=SezioneSeeder --force
  Nel .env del server: OCR_SPACE_KEY=la-chiave, poi php artisan config:cache.
  In cPanel > Select PHP Version: estensioni gd ed exif attive (foto ridotta e raddrizzata).
  I consiglieri si creano come gli altri utenti (deploy.md par. 3.8, 'ruolo' => 'consigliere').
  Verifica: pagina Scontrini da Tesoriere, sotto l'elenco "Lettura automatica delle foto: attiva".
  APP_DEBUG del server: ancora da rimettere a false prima dell'apertura.
