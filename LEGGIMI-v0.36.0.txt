Gestionale ASD - v0.36.0 (07/10/2026)
Rinnovi quota e Promemoria

Da applicare sopra la v0.35.1. 2 migration, 3 seeder, CSS e JavaScript (npm run build).
Schede: docs/specifiche/rinnovi-quota.md, promemoria.md. Tavole: docs/mockup/Tavole-rinnovi-quota.pdf.

COSA CAMBIA
  - Rinnovi quota (menu "Rinnovi quota"): elenco dell'anno sociale con la situazione di ogni socio
    (in regola, da versare entro il 31/01, in ritardo con voto sospeso, da dichiarare decaduto dal
    1 maggio), registrazione della quota con ricevuta numerata per anno di pagamento (13/2027),
    movimento in Prima Nota, ricevuta PDF per email al socio o al genitore, annullamento motivato.
    Le quote sono anche nella scheda del socio.
  - La prima quota dalla domanda online ha la ricevuta numerata, allegata all'email di benvenuto.
  - Contabilita' nel gestionale dal 2027 (impostazione contabilita_anno_avvio): una quota incassata
    prima ha ricevuta ma niente movimento (l'incasso e' nel vecchio gestionale).
  - Detrazione per lo sport dei ragazzi sulla ricevuta solo con l'ente iscritto al RASD (la B.A.S.
    non lo e': nel 2027 mai).
  - Promemoria (menu "Promemoria", gruppo Governance): email automatiche con date e testi
    modificabili, anteprima, prova, storico. Pronti: invito 15/12, sollecito 1/02, ultimo avviso 1/04.
  - MANUALE par. 2.3: il passaggio all'esenzione IVA e' rinviato al 2036.

LOCALE
  1. Estrarre lo ZIP nella radice (sovrascrivere); cancellare LEGGIMI-v0.35.1.txt.
  2. php artisan migrate
     php artisan db:seed --class=ImpostazioneSeeder
     php artisan db:seed --class=SezioneSeeder
     php artisan db:seed --class=PromemoriaSeeder
  3. php artisan test   -> 75 superati
  4. git add -A && git commit -m "v0.36.0: Rinnovi quota e Promemoria"
  5. npm run build ; git archive -o deploy.zip HEAD ; build.zip da public\build

SERVER
  Come le ultime (deploy.md par. 5: unzip, build.zip, migrate --force, optimize:clear e cache),
  con in piu' dopo "php artisan migrate --force":
     php artisan db:seed --class=ImpostazioneSeeder --force
     php artisan db:seed --class=SezioneSeeder --force
     php artisan db:seed --class=PromemoriaSeeder --force
  I seeder aggiungono solo cio' che manca (SezioneSeeder riscrive i permessi dei ruoli come da
  matrice standard). Il cron "schedule:run" ogni minuto c'e' gia': i promemoria partono da soli.
  Verifica: php artisan promemoria:invia --prova (nessuna riga = nessun promemoria in scadenza oggi).
